## 🚀 Apa Itu FinNote?

**FinNote** adalah aplikasi catatan keuangan yang dirancang buat kamu yang pengen ngatur duit dengan lebih santai, tapi tetap keren. Gak pake ribet, gak pake Excel, tinggal catat dan kontrol arus keuanganmu langsung dari browser! 🧠💰

---

## ✨ Fitur-fitur Canggih

- 📥 **Catat Pemasukan & Pengeluaran** semudah ngetik "makan siang 25k"
- 📊 **Statistik Harian & Bulanan** biar kamu tau kemana duitmu terbang
- 🎨 **UI Kekinian** pake Tailwind dan ShadCN, dijamin seger di mata!
- 🌙 **Dark/Light Mode** tinggal klik, langsung berubah suasana~
- 👤 **Akun & Profil** supaya datamu aman dan personal banget
- 🔐 **Fast & Secure** pake Next.js + TypeScript = auto kenceng!

---

## 🛠️ Teknologi di Balik Layar

| 🔧 Stack      | Detail Keren                      |
|--------------|-----------------------------------|
| Next.js 14    | Framework andalan masa kini       |
| React 18      | UI interaktif yang mantep         |
| Tailwind CSS  | Styling yang ringkes & stylish    |
| ShadCN UI     | Komponen siap pakai yang kece     |
| TypeScript    | Supaya gak typo di dompet virtual |
| Zustand       | State management yang minimalis   |

## 🎮 Coba Sendiri Yuk!

```bash
# Clone dulu
git clone https://github.com/kamu/FinNote.git
cd FinNote

# Install semua kebutuhan
pnpm install

# Jalanin server lokal
pnpm dev
```

🔗 Akses via browser: [https://finnote.zora.my.id]
